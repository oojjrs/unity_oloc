# 애셋 출처와 사용 주의

이 패키지의 PNG는 제3자 국기 아이콘 팩에서 복사하지 않았습니다. 각 국기를 built-in ImageGen으로 새로 생성한 뒤 공식 비율에 맞춰 후처리했습니다.

국기는 국가상징입니다. 이 패키지는 국가상징 자체에 독점 권리를 주장하지 않으며, 국가별 사용 제한·표장 규정·표현 정확성까지 보증하지 않습니다. 특히 문장과 국장이 포함된 국기는 작은 UI에서 단순화될 수 있으므로 정부·법률·의전·인쇄 용도로 사용하면 안 됩니다. 상업 출시 전에는 대상 국가와 배포 지역의 규정을 별도로 검토해야 합니다.

국기는 언어와 동일하지 않습니다. 영어·번체중국어·중남미 스페인어의 국가 표시는 대표 지역일 뿐이며, UI에서는 로케일의 현지어 이름을 함께 보여야 합니다.
