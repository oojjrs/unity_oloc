# 아트 제작

국기 16종은 기존 프로젝트 이미지를 입력으로 사용하지 않고 built-in ImageGen으로 각각 새로 제작했습니다.

ImageMagick은 신규 생성 원본의 크로마키 제거, 투명 여백 정리, 256×256 캔버스 중앙 배치와 정확한 국기 비율 보정에만 사용했습니다. 최종 PNG는 `Runtime/Sprites`에 있으며 제작 후보와 중간 파일은 패키지에 포함하지 않습니다.

국기 필드는 미국 19:10, 브라질 10:7, 독일 5:3, 폴란드 8:5, 멕시코 7:4, 나머지 11개 3:2 비율을 유지합니다.

국가상징의 사용과 표현상 주의는 [NOTICE](NOTICE.md)를 참고하세요.
